Keiro is a self-hostable RAG infrastructure with three-tier adaptive retrieval, semantic caching, namespace isolation, and full observability. Go gateway. Python intelligence layer. One docker compose up.

Key Features

Everything you need for production-grade RAG, nothing you don't.

🔀
01 — RETRIEVAL
Three-Tier Adaptive Retrieval
Hybrid BM25+dense, Multi-Vector with MMR reranking, and Self-Querying multi-hop. Query complexity drives strategy selection automatically.
⚡
02 — CACHING
Semantic Cache
Cosine similarity lookup against cached embeddings. Configurable threshold (default 0.92). Namespace-scoped — no cross-tenant leakage.
🏢
03 — ISOLATION
Namespace Isolation
Each namespace is an isolated ChromaDB collection. Shared-secret auth with per-namespace rate limiting via token bucket.
📊
04 — OBSERVABILITY
Prometheus + Grafana
Cache hit rate, per-tier latency histograms, token usage by namespace and model, ingestion throughput — pre-built dashboard included.
🔌
05 — SDK
Python SDK
pip-installable keiro-client with query(), ingest(), and job_status(). Pydantic models. Clean exception hierarchy. 5-line quickstart.
🚀
06 — DEPLOYMENT
Zero-Config Deploy
docker compose up starts everything. Set KEIRO_SECRET and KEIRO_EMBEDDING_MODEL=local in .env. No cloud account needed.
